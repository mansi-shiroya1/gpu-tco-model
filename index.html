Self-host or call an API?

Llama 3.x 70B (FP8) served with vLLM, versus hosted APIs for the same model. Cost per 1,000 requests of 1,024 input and 256 output tokens.

Throughput is measured on 4× H100 SXM with NVLink (batch: 256 concurrent requests; interactive: 64 users at ~22 tok/s each). A PCIe server is likely slower, which raises every self-host break-even.

What this model leaves out

  • CPUs, memory, storage, power supplies, networking, and installation. These all raise owned cost.
  • Engineering and support staff time to run self-hosted models.
  • Financing, taxes, resale value, failures, and spares.
  • Reserved, committed-use, and negotiated discounts on rentals and APIs.
  • Power is at rated maximum, not measured draw. Quality parity between self-hosted and API models is assumed.
  • Prices move monthly; every figure is dated.
